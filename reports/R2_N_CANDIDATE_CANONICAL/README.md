# N：M 单点候选的几何表示规范化

默认关闭。新开关为 `canonical_single_candidates`，只在传入 M 的 `candidate_points` 前生成规范化多边形副本；位置假设、恢复费用、实际 RF 更新、保证清除与退出仍接收原硬 P。

`code/candidate_geometry.py::canonical_candidate_polygon` 先平移并按跨度归一化，以固定排序的凸包去掉冗余共线顶点。返回点是原输入顶点的子集，没有修改输入、扩大或改写实际保守区域。有限极端坐标造成跨度溢出时显式拒绝。

旧 M 使用遍历中首次遇到的并列直径决定侧向法线。对矩形 `[(0,-10),(1000,-10),(1000,10),(0,10)]`，当前位置 `(-100,0)`，循环一次首顶点会将另一条对角线选作直径，37 个候选的集合距离达 15.996801 米。N 规范化后，循环、逆序及不均匀共线细分的 37 个候选按相同顺序完全一致。

新增四项单测还覆盖 100 个随机凸多边形及退化输入。独立 optical worker 确认副本仅返回输入顶点子集、不会写入原 P。这个性质不能证明 N 更快；当前按要求没有执行任何完整场景，也没有启用为当前最佳方案。

本工作树未集成父任务的 M，因此提供基于父提交 `6b4ab49` 的具体 `integration.patch`，只增加一个导入及候选生成前的可选规范化步骤。父任务合并辅助模块后应用该补丁即可。新配置 `configs/R2_N_canonical_single.json` 基于 M，只开启 N。

后续应对同场景比较 M 与 M+N，将候选表示规范化作为独立因素；不要把现有 M 已跑成绩记作 N 成绩。
